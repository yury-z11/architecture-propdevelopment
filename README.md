# Architecture PropDevelopment — Sprint 5

## Что сделано

### Task1 — Классификация данных и риски (Mindmap)
- Построена mindmap (draw.io) с классификацией данных компании по 4 категориям: публичные / внутренние / конфиденциальные / секретные.
- Для каждой категории описаны риски (утечка, потеря, искажение, некачественные данные, обесценивание) и дана оценка влияния (незначительный/значительный/критический).

Артефакты: `Task1/`

- Там, где информации в кейсе недостаточно, указаны вопросы для уточнения на аудите.

Артефакты: `Task2/`

### Task3 — Интеграции “Умный дом” (C4 + требования)
- Добавлены внешние интеграции: умный домофон (распознавание лиц) и умный шлагбаум (распознавание номеров).
- Обновлены диаграммы C4: контекст и контейнеры (интеграционный сервис/адаптер).
- Описаны требования по безопасности, аутентификации/авторизации и взаимодействию (webhooks/ретраи/аудит).

Артефакты: `Task3/`

### Task4 — RBAC в Kubernetes (роли + скрипты)
- Спроектирована ролевая модель доступа (минимум 3 роли) для Kubernetes.
- Подготовлены скрипты:
  - создание пользователей,
  - создание ролей,
  - привязка ролей (RoleBinding/ClusterRoleBinding).
- Добавлены команды проверки прав через `kubectl auth can-i`.

Артефакты: `Task4/`

### Task5 — NetworkPolicy (изоляция трафика)
- Развёрнуты 4 сервиса (nginx) с labels: `front-end`, `back-end-api`, `admin-front-end`, `admin-back-end-api`.
- Реализованы NetworkPolicy: deny-by-default + разрешение трафика только внутри пар:
  - `front-end` ↔ `back-end-api`
  - `admin-front-end` ↔ `admin-back-end-api`
- Добавлены команды проверки доступности/недоступности через тестовые pod’ы.

Артефакты: `Task5/`
